# Жесты и настройки

Жесты драйвера делает библиотека [gestus](https://github.com/Redox-openDriver/gestus). Всё, что умеет тачпад сверх
обычного набора, включается в одном файле настроек. Без файла драйвер ведёт себя как раньше: указатель, тапы, клик по
числу пальцев, прокрутка двумя пальцами. У каждой функции свой раздел и свой выключатель `enabled`; всё выключено,
пока не включишь. Все разделы, параметры, действия и ползунки описаны в
[справочнике gestus](https://github.com/Redox-openDriver/gestus/blob/main/docs/settings.md); установщик кладёт его копию
в `/usr/local/share/doc/elantp/settings.md`.

## Где лежит файл
| система | файл | как применяется |
|---|---|---|
| Linux, служба `elantpd` | `/etc/elantp/gestures.toml` | перечитывается на ходу, через секунду после сохранения |
| Linux, `elantp-dev drive` | `/etc/elantp/gestures.toml` или `--config <файл>` | перечитывается на ходу |
| Redox, служба `elantpd` | `/etc/elantp/gestures.toml` | при запуске службы |

## Два режима
**Служба на Linux работает в родном режиме.** Обычное поведение тачпада — указатель, тапы, прокрутка, щипок, свайпы
рабочих столов, отключение при наборе, правая кнопка — делает libinput, и всё это настраивается в параметрах GNOME,
KDE и других окружений, как у любого тачпада. Наш драйвер добавляет только свои жесты и прячет от системы касания,
которые они заняли. Работают разделы `corners`, `rails`, `circular`, `edge-swipes`, `joystick`, `symbols`,
`numpad`, `cover`, `shake`, `dwell`, `smoothing`, `tablet`, `edge-motion`; разделы `pointer`, `taps`, `inertia`,
`throw`, `drag`, `swipes`, `rotate`, `pinch`, `sniper`, `knock`, `areas` и `typing` в этом режиме не действуют —
их заменяют настройки окружения. Если ни один из работающих разделов не включён, служба тачпад не трогает вовсе.
Для `cover` служба следит за моментами нажатий клавиш: ладонь, которая легла при наборе текста, накрытием не считается.
На Redox нажатия клавиш драйверу пока не видны, и там такая ладонь может сработать как накрытие.

Касание, которое может оказаться нашим жестом, система не видит, пока не станет ясно: палец у края с рейкой ждёт,
пока сдвинется; тап в углу с двойным касанием ждёт второго. Если жест не получился, палец сразу показывается системе,
нажатие площадки проходит всегда, а короткий тап повторяется для неё — щелчок тапом не теряется.

**`elantp-dev drive` и Redox работают нашим движком целиком**: действуют все разделы, а настройки окружения — нет.

Свои символы, выученные командой `learn`, лежат рядом в `symbols.toml`. Пример, где включено почти всё, —
[`config/gestures.toml`](../config/gestures.toml).

```sh
sudo target/release/elantp-dev drive --config config/gestures.toml
```

Ошибка в файле не ломает драйвер: `drive` скажет строку и столбец и оставит прежние настройки, служба Redox
запустится с обычным набором. Проверить настройки на своих записях касаний можно без тачпада:

```sh
target/release/elantp-dev gestures --config config/gestures.toml captures/scroll.tprec
```

## Свои символы
Нарисованные символы включаются разделом `[symbols]`; к 17 встроенным можно добавить свои:

```sh
sudo elantp-dev learn spiral
```

Символ рисуется три раза одним пальцем, курсор в это время стоит. Образцы попадают в `symbols.toml` рядом с файлом
настроек, по умолчанию `/etc/elantp/symbols.toml`; служба перечитывает их вместе с настройками. Если пробуешь свой
файл настроек, положи образцы рядом с ним: `--file config/symbols.toml`. Действие символу назначается в
`[symbols.actions]` по имени.

Как драйвер видит твои символы, покажет запись: `elantp-dev symbols captures/symbols.tprec` называет для каждого
штриха одним пальцем самый похожий символ и его сходство; символ срабатывает от 0.8. Если твой символ стабильно ниже,
выучи его своим почерком через `learn`.

## Что учесть
- Linux: громкость, яркость и мультимедийные клавиши обрабатывает окружение рабочего стола; в Redox пока передаются
  только громкость, медиа, печать экрана и обычные клавиши — о прочих служба один раз напишет в журнал.
- Пороги жестов подобраны на записях обычной работы, чтобы не было ложных срабатываний: ни одна из девяти записей с
  примером настроек не нажимает лишнего.
