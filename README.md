# elantp-327e — открытый драйвер тачпада ELAN 04F3:327E

An open driver for the ELAN 04F3:327E touchpad (an I2C HID Windows Precision Touchpad) aimed at Redox OS, developed and
tested on Linux first: report parsing, contact assembly, its own gesture engine (pointer acceleration, taps, clicks by
finger count, two-finger scrolling, swipes, thumb and palm rejection tuned on real recordings), and on Redox a
DesignWare I2C master, AMD GPIO interrupts and HID over I2C feeding `inputd`. It runs only with the exact pad it was
verified on. The documentation below is in Russian.

Тачпад ноутбука Lenovo ThinkBook 16 G6 ABP (21KK): ELAN06FA, HID 04F3:327E на шине I2C, стандартный Windows Precision
Touchpad (пять касаний, площадка-кнопка 117 × 72 мм). Реверс не понадобился: HID over I2C и Precision Touchpad описаны
открыто.

> Независимый открытый проект. Не связан с ELAN Microelectronics; название ELAN указано только для обозначения совместимого устройства.

## Что готово
| часть | состояние |
|---|---|
| `core` | разбор дескрипторов HID, раскладка Precision Touchpad, сборка касаний, команды HID over I2C, ресурсы ACPI, контроллер I2C DesignWare, прерывания GPIO AMD, запуск тачпада — без привязки к ОС, `no_std` |
| `linux` | служба `elantpd`: тачпад отдаётся системе через виртуальный тачпад, поэтому его настраивают GNOME, KDE и другие окружения, а наши жесты работают поверх; `elantp-dev`: сведения о тачпаде, пошаговая запись касаний (`session`), разбор записей, наш движок вживую (`drive`), обучение символам (`learn`) и их проверка на записи (`symbols`) |
| `redox` | служба `elantpd`: ресурсы из ACPI через `acpid`, регистры контроллеров, прерывание, события в `inputd`; собрана, но на ноутбуке ещё не проверена |

## Жесты сверх обычного
Жесты делает отдельная библиотека [gestus](https://github.com/Redox-openDriver/gestus). Всё включается в файле настроек, у каждой функции свой выключатель, без файла работает обычный набор:
прокрутка по инерции и бросок курсора; выключение тачпада двойным касанием угла, горячие углы и код постукиванием;
перетаскивание тремя пальцами, движение у края и переключение окон свайпом; рейки громкости и яркости двумя
пальцами у краёв, круговая прокрутка, поворот и щипок; нарисованные символы, в том числе выученные свои; цифровой
блок на площадке; снайперский режим, джойстик в углу, клик задержкой, сглаживание дрожания, «накрыть ладонью»,
встряска для поиска курсора, режим планшета, смахивание от края и правая кнопка в углу. Как настройки устроены в
этом драйвере — [docs/gestures.md](docs/gestures.md), все разделы и параметры — в
[справочнике gestus](https://github.com/Redox-openDriver/gestus/blob/main/docs/settings.md), пример с почти всем
включённым — [config/gestures.toml](config/gestures.toml).

## Установить на Linux
```sh
sh linux/dist/install.sh
```
Установщик собирает драйвер, ставит службу `elantpd` для systemd, OpenRC, runit, dinit или s6 и запускает её.
Без файла `/etc/elantp/gestures.toml` служба тачпад не трогает: он работает как обычно и настраивается в параметрах
окружения. Когда в файле включены наши жесты, служба забирает тачпад себе и показывает системе виртуальный тачпад с
тем же именем и кодами: скорость, тап, естественная прокрутка, отключение при наборе и свайпы рабочих столов по-прежнему
берутся из GNOME, KDE, XFCE, Sway и любых других окружений на libinput, а касания, занятые нашими жестами (углы,
рейки, символы, джойстик), система просто не видит. Файл перечитывается на ходу. Переключения — цифровой блок, режим
планшета, выключенный тачпад, распознанный символ — показывает уведомлениями `elantp-notify`: он запускается со входом
в сеанс через автозапуск рабочего стола. Удалить: `sh linux/dist/uninstall.sh` (`--purge` — вместе с настройками).

## Попробовать наш движок на Linux
```sh
cargo build --release
sudo target/release/elantp-dev drive
```
Это режим разработки: курсором управляет наш движок целиком, как будет в Redox, и настройки окружения на него не
действуют. Ctrl+C всё возвращает. Если служба уже держит тачпад, сначала останови её: `sudo systemctl stop elantpd`.
`--natural` — естественная прокрутка, `--speed 0.7` — медленнее, `--config config/gestures.toml` — с новыми жестами;
файл перечитывается на ходу, как только его сохранишь. `sudo target/release/elantp-dev learn spiral --file
config/symbols.toml` — выучить свой символ. `sudo target/release/elantp-dev session` — записать свои
касания с подсказками (тачпад на время записи не двигает курсор).

## Устройство
Тачпад отвечает на адресе 0x15 шины `\_SB.I2CA` (контроллер DesignWare AMDI0010, 400 кГц, тактовая частота 150 МГц),
о новых касаниях сообщает выводом 9 контроллера GPIO AMD (AMDI0030, общее прерывание 7). Драйвер работает только с
проверенным вариантом: HID 04F3:327E с дескриптором отчётов из 675 байт; другие тачпады этой модели ноутбука (Synaptics,
FocalTech, Goodix, Cirque) он не трогает. Служебные отчёты тачпада для обновления прошивки драйвер построить не может.
